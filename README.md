# Awesome Chocolate Sales Analysis | Power BI

## Project Overview
This project presents an interactive sales analysis dashboard developed using Microsoft Power BI to analyze chocolate sales performance from 2023 to 2026.
The dashboard provides insights into revenue, profitability, orders, product performance, country-level sales, and salesperson contributions.

## Dashboard Pages
- **Executive Overview:** Key performance indicators, revenue trends, sales team performance, and product category profitability.
- **Country Analysis:** Revenue trends, country-level performance, order breakdown, and year-over-year growth.
- **Product Analysis:** Top-performing products, product categories, sales quantities, costs, discounts, and profit margins.
- **Salesperson Performance:** Salesperson rankings, team revenue, profit margins, and order performance.
- **MTD Analysis:** Month-to-date cumulative revenue analysis.
- **QTD Analysis:** Quarter-to-date cumulative revenue analysis.
- **YTD & Growth Analysis:** Yearly revenue comparison and year-over-year growth.
